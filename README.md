# Quantum Computing Bachelor Project

This repository contains the Qiskit implementations, simulations, and examples developed as part of my Bachelor's project in Physics.

The project focuses on the fundamental concepts of quantum computing and the implementation of quantum algorithms. The code is organized according to the structure of the accompanying bachelor's project report.

## Contents

### Chapter 2 — Quantum Computing Foundations

This section contains implementations and examples related to the mathematical and physical foundations of quantum computing, including:

* Qubits and quantum states
* Bloch sphere
* Quantum measurements
* Single-qubit quantum gates
* Multi-qubit gates
* Entanglement and Bell states

### Chapter 3 — Quantum Algorithms

This section contains implementations of quantum algorithms discussed in the project, including:

* Deutsch algorithm
* Grover algorithm
* Shor algorithm

## Software and Tools

The implementations are developed using:

* Python
* Qiskit
* Qiskit Aer
* NumPy
* Matplotlib

## Purpose

The purpose of this repository is to provide the computational examples and Qiskit implementations accompanying the theoretical discussions presented in the bachelor's project.

The code is intended both to illustrate the underlying concepts and to reproduce the quantum circuits and simulations discussed in the project.
